# MERIDIAN — wellness in rhythm with the day

An eight-page site for **MERIDIAN**, a fictional wellness practice in Ojai, California.

Static, dependency-light, no build toolchain. `meridian/` is its own deployable site
root — it carries its own `vercel.json` and is served at `/`, not under a subpath.

```bash
# Serve THIS directory as the site root, with clean-URL emulation
npx http-server meridian -p 8001 --ext html
# open http://localhost:8001
```

`--ext html` mirrors Vercel's `cleanUrls`, so `/rhythm` resolves to `rhythm.html`.

## Live

<https://meridian-wellness-rouge.vercel.app>

The bare `meridian-wellness.vercel.app` belongs to an unrelated project — `*.vercel.app`
is a global namespace. `BASE_URL` in `build/partials.py` is the one place the canonical
origin is set; change it there if a custom domain is attached and rebuild.

## The idea

The organizing spine is the **day**, not a curriculum. Four hours, each with its own
physiology, its own practices, and its own colour:

| Hour | Window | For |
| --- | --- | --- |
| **Dawn** | 05:30–09:00 | Light, breath, waking the body |
| **Meridian** | 11:00–14:00 | Load, focus, eating properly |
| **Dusk** | 16:30–19:30 | Downregulation, sound, slow tissue |
| **Deep** | 21:00–05:00 | Sleep, repair, the actual adaptation |

That structure is load-bearing rather than decorative. **Hue equals hour** everywhere:
the ambient page wash retints as you scroll past each phase, the day-arc graphic moves a
sun along its path and recolours at each stage, and a practice card badged *Dusk* sits on
dusk-tinted artwork. `build/build.py` and `build/art.py` are kept in sync on this — there
is a check in the build notes below.

## Type & colour

Warm off-white ground (`#FBF8F3`) with near-black warm ink and **sage** (`#5E7154`) as the
one constant accent; the four phase hues are the variable. Display face is **Fraunces**
(variable, with its `SOFT` and `WONK` axes turned up), body is **DM Sans**. Both are
self-hosted latin subsets — 424 KB, no CDN.

## The artwork

**Every image is generated by `build/art.py`** — 24 procedural SVGs, deterministic and
seeded, so a rebuild reproduces them byte-for-byte. Four generators (`light_study`,
`ripple`, `dune`, `bloom`) parameterised by phase hue and seed, which is what keeps two
dozen artworks reading as one body of work.

```bash
python3 build/art.py     # regenerate the 24 artworks
python3 build/build.py   # regenerate the eight HTML pages
```

### Media slots — read this before adding photography

The artwork occupies the slots photography and film would. **The intent was to generate
these with Higgsfield**, but the account's daily generation cap was exhausted and blocked
every model, video and image alike, for the whole build. The procedural set was built to
stand on its own rather than to look like a placeholder.

To swap in real media later, replace the file and update the `src`:

| Slot | Files | Wants |
| --- | --- | --- |
| Hero | `hero-dawn.svg` | Dawn light through linen, dust in a sunbeam — film |
| Phases | `phase-{dawn,meridian,dusk,deep}[-wide].svg` | One light study per hour |
| Practices | `practice-{breath,movement,sound,restore,nourish}.svg` | The practice in the room |
| Guides | `guide-{1..4}.svg` | Portraits, 4:5, soft natural light |
| Journal | `journal-{1..3}.svg` | Editorial headers |
| Retreats | `retreat-{1..3}.svg` | Ojai valley and ridge |

Keep the hue/hour rule when you do: a card badged *Dusk* wants dusk-toned imagery.

## Motion

GSAP + ScrollTrigger, vendored in `assets/js/vendor/` (no CDN).

- **Ambient phase light** — whichever hour is nearest the middle of the viewport sets
  `--phase` / `--phase-wash` on `<html>`; the page warms and cools as you read.
- **The day arc** — a scrubbed sun travels the path, drawing the trail behind it and
  recolouring at each phase.
- **Hero** — word-by-word rise on load.
- **Cards, tiers, rows** — CSS hover lift with artwork zoom. Reveals hand elements back
  to CSS on completion (`clearProps`), because GSAP's leftover inline transform otherwise
  outranks `:hover` and silently kills the lift.
- **Counters** — with years excluded, since counting up to "2016" reads as nonsense.

Everything is applied *from* JavaScript, so pages render complete with JS blocked, and all
motion is skipped under `prefers-reduced-motion`.

## Mobile

Below 860px card grids become swipeable snap rails with dot indicators, the nav collapses
to a sheet (its CTA is hidden — the sheet carries its own), phase blocks stack with the
artwork on top, and pricing stacks with the middle tier still flagged.

## Content

Everything is invented — the practice, its guides, the address, the prices, the schedule.
The phone number uses the 555 reserved range. Both forms are front-end only.
