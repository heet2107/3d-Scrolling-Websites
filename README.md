# Heet Barot — Cinematic Portfolio

Cinematic portfolio of Heet Barot — AI Engineer & Full-Stack Developer.

Built on the open-source [cinematic-portfolio](https://github.com/VaibhavKhushalani/cinematic-portfolio)
codebase by Vaibhav Khushalani, personalized with Heet's resume, projects, and
AI-generated identity graphics (Higgsfield).

**Live:** [heet-barot-portfolio.vercel.app](https://heet-barot-portfolio.vercel.app)

## Stack

Next.js 16 · React 19 · Tailwind 4 · GSAP · Three.js

## Develop

```bash
npm install
npm run dev
```

All personal content lives in `data/profile.json` and `data/content.json`.
